# 📱 Chatty - Android AI Copilot

**Chatty** is a privacy-focused Android client for ChatGPT, Claude, Gemini, DeepSeek, and local LLMs (Ollama), built on top of [Chatbox](https://github.com/chatboxai/chatbox).

---

## 🌟 Key Modifications from Upstream Chatbox

### 1. 🚫 Removed Chatbox AI Cloud Account Gates
* **No Account Required**: The proprietary Chatbox AI account registration/login flow and paywalls have been completely removed.
* **Direct BYOK (Bring Your Own Key)**: Settings defaults directly to Model Providers. Connect directly to your own API keys:
  * OpenAI (`gpt-4o`, `o1`, `o3-mini`, etc.)
  * Anthropic Claude (`claude-3-5-sonnet`, `claude-3-7-sonnet`, etc.)
  * Google Gemini (`gemini-2.5-pro`, `gemini-2.0-flash`, etc.)
  * DeepSeek (`deepseek-chat`, `deepseek-reasoner`)
  * Ollama / Local LLMs (over LAN or local Wi-Fi)
  * Groq, Moonshot, SiliconFlow, Zhipu, and custom OpenAI-compatible endpoints.
* **Offline Document Parsing**: Document and file parsing defaults to local offline parsers, keeping your data private on device.

### 2. 🛠️ Work Mode (Agent Execution & Artifacts) on Android
* **Enabled for Mobile**: Work Mode (previously restricted to desktop Electron builds) is now fully enabled on Android.
* **Interactive Artifact Previews**: HTML, SVG, Markdown, and code artifacts generated by AI can be viewed and run directly inside a sandboxed mobile iframe view.
* **Reasoning Control**: Dedicated reasoning effort controls (Low, Medium, High) for thinking models (`o1`, `o3-mini`, `deepseek-r1`).

### 3. 🔌 Model Context Protocol (MCP) Support on Mobile
* **Mobile MCP Transports**: Fully enabled MCP client support for Android using Streamable HTTP and Server-Sent Events (SSE) transports.
* **Local Network (LAN) Support**: Configured `usesCleartextTraffic="true"` in AndroidManifest to enable seamless connections to MCP tool servers running on your local home/office Wi-Fi (e.g. `http://192.168.x.x:port`).

## 🚀 How to Install on Android

1. Download **[`Chatty-Android-debug.apk`](./Chatty-Android-debug.apk)** to your Android device (or transfer it from your PC via USB / file transfer).
2. Tap the APK file to install.
3. If prompted, allow **"Install unknown apps"** in Android Settings.
4. Launch **Chatty**, go to **Settings -> Model Provider**, enter your API key or Ollama host, and start chatting!

## 🛠️ Building from Source

### Prerequisites
* **Node.js**: v22.13.0 or higher
* **pnpm**: v10.17.0 or higher
* **Java**: OpenJDK 21 LTS (`JAVA_HOME` configured)
* **Android SDK**: Build Tools 34.0.0+, Android SDK Platform 34

### Build Steps
```bash
# 1. Install dependencies
pnpm install

# 2. Build the Android web assets and sync Capacitor
pnpm run mobile:sync:android

# 3. Compile the Debug APK
cd android
./gradlew assembleDebug   # On Windows: .\gradlew assembleDebug
```
The compiled APK will be output to:
`android/app/build/outputs/apk/debug/app-debug.apk`
